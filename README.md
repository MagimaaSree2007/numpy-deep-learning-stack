# numpy-deep-learning-stack
A lightweight, custom deep learning library and training pipeline built completely from scratch using pure NumPy (no external deep learning frameworks like PyTorch or TensorFlow allowed). This project was designed to fulfill advanced academic and engineering requirements, culminating in a custom Convolutional Neural Network (CNN) achieving over 91% test accuracy on Fashion-MNIST and optimized for microcontroller deployment via Post-Training INT8 Quantization.
Custom Autograd Engine (Tensor): Implements dynamic computational graphs with reverse-mode automatic differentiation (.backward()) and topological sorting.   Custom Mathematical Operations: Broad-supported operations including matrix multiplication, element-wise addition, activation functions (ReLU), and numerically stable Softmax Cross-Entropy Loss.Hand-Coded Optimizers: Custom implementations of Stochastic Gradient Descent (SGD) with Momentum and Adam Optimizer.   Advanced Spatial CNN Layers:Conv2D powered by efficient im2col and col2im matrix transformations.   MaxPool for downsampling.   BatchNorm (Batch Normalization) with distinct train/evaluation mode switches.   Dropout for regularization.   Hardware-Ready Optimization: Designed for post-training 8-bit integer (INT8) quantization to run efficiently on resource-constrained microcontrollers
